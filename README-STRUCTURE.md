# Project Structure
bot contains WhatsApp runtime, routing, payment and group services.
database contains repository, SQL schema, migrations, backup and statistics.
web contains Express API and browser dashboard.
deploy contains Docker, Compose, environment template, Nginx and shell helpers.
test contains automated Node tests for orders, payments, web, security, groups and receipts.
types contains TypeScript contracts for orders, payments, config and groups.
python contains health, analytics, export, payment and reporting helpers.
config contains brands, roles, messages and payment rules.
scripts contains line checks, deployment, backups and demo seeding.
docs contains architecture, API, security, commands and deployment notes.
styles contains reusable admin and brand CSS.
